The carousel design system for @goldenhorseshoewatch, built on Alex Pereira's Grow with Alex method,
with a monochrome place-imagery layer so every slide names its city before the headline does.

- `design/` — Claude Design artboards for every slide type plus the nine-tile grid test.
- `docs/signal-imagery.md` — the Golden Horseshoe place library and Higgsfield prompt templates.
- `docs/higgsfield-renders.md` — every render so far, by job ID.
- `skills/ghw-carousel/` — the draft skill this system becomes.
- `reference/grow-with-alex/` — Alex's documents and 16 of his 17 skills, verbatim from Dropbox.
- `reference/golden-horseshoe-watch/` — the account's idea bank, competitor report and research brief.
