# Slide templates

Claude Design artboards for the Golden Horseshoe Watch carousel system v2. Each `.dc.html` is one
1080x1350 slide type; `canvas.json` lays them out on two pages ("Slide types", "Grid rhythm") and
carries the system rules as notes. Edit these files and re-seed; never hand-edit the published canvas.

| File | Slide type | Tile | Brand mark |
|---|---|---|---|
| `Main.dc.html` | Cover, explainer / checklist | PHOTO | Yes |
| `Item.dc.html` | Numbered item | PHOTO | No |
| `Stat.dc.html` | Stat / fact | LIGHT | No |
| `Turn.dc.html` | Both-sides turn | ACCENT | No |
| `Story.dc.html` | Real case | PHOTO | Never |
| `Close.dc.html` | Last slide | dark solid | No |
| `Grid.dc.html` | Nine covers as the profile grid | mixed | — |

Dashed zones mark where the monochrome Higgsfield place plate drops in (see `docs/signal-imagery.md`).
