# Slide templates

Claude Design artboards for the Golden Horseshoe Watch carousel system. Each file is
one 1080x1350 slide type; `canvas.json` lays them out and carries the system rules
as notes. Edit these files and re-seed the canvas; never edit the published canvas
file by hand.

| File | Slide type | Brand mark |
|---|---|---|
| `Main.dc.html` | Cover (explainer / checklist) | Yes, full-bleed art under the type |
| `Item.dc.html` | Numbered item | No |
| `Story.dc.html` | Real case / story | Never. Amber rule instead. |
| `Close.dc.html` | Last slide, save + DM "WATCH" | No |
