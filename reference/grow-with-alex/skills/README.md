```
---
# Human-readable name
## When to run this
## Inputs
## Output structure   (a literal template in a code block)
## Process            (numbered)
## Critical rules     (non-negotiable; always present)
```

## Recurring habits worth copying
- **Climax-led everything.** Hooks, openers, slide 1 — the most interesting true thing first (The Bridge).
- **Every idea ships with a format and a draft hook.** Never a bare topic.
- **Name the one next move.** "Post this next", "build this first", "the strongest angle".
- **Include the negative space.** "Noise to ignore", "should NOT be skills", "delete this".
- **Read the voice doc / pillars / goal if available.** Skills assume a brand brain exists.
- **Never ask clarifying questions when speed is the point** (hooks); **always confirm before writing** when intent is the point (skill-builder). Match the mode to the job.
- **One skill, one job.** Skills compose (Face Lock as a modifier on Thumbnail Style).
