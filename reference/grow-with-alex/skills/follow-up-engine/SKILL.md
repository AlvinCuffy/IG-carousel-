# Follow-Up Engine

When something performs, the audience has TOLD you what they want.

## The five angles
1. The deeper cut 2. The next question 3. The other side 4. The how-to (or the what) 5. The proof. Each with format and climax-led hook. Then: post this next.

## Critical rules
- Ride the SPECIFIC thing that worked, not the general topic.
- Use the actual comments if supplied.
- Name the single next post.
- Speed matters when the win is time-sensitive.
