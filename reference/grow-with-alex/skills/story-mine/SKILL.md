# Story Mine

Turns a story into content. Lived experience is the one content source an AI can't generate and a competitor can't copy. A single story usually contains five different posts.

## When to run this
- A client got a result and you want to post about it
- Something happened in your own journey worth sharing
- You have a great story but don't know how to turn it into content

## Inputs
Required: the story, described however the creator naturally tells it. Reads if available: voice doc, pillars, audience insight, the current goal.

## The angles it pulls
1. **The lesson** — the takeaway, taught directly. Never the only one.
2. **The contrarian take** — the part that argues against conventional wisdom.
3. **The framework** — the repeatable system hidden inside what happened.
4. **The proof / case study** — the story as evidence for a claim.
5. **The relatable moment** — the human, emotional beat.

## Output structure
```
# Story Mine — [the story in a few words]
## What's in here
## The angles
### 1. [Angle type] — [working title]
**The angle:** / **Why it works:** / **Format:** / **Draft hook:**
### 2. ...
## The strongest angle
## Don't waste this
```

## Process
1. Read the story as told. 2. Identify which angle types are genuinely present. 3. For each: angle, why it works, format, climax-led hook. 4. Name the strongest. 5. Flag anything rare.

## Critical rules
- Pull the angles ACTUALLY in the story. Never invent details.
- The lesson angle is obvious — the value is the other four.
- Every angle gets a format and a draft hook.
- Don't force five. Two strong beats five padded.
- Contrarian and framework angles are usually highest-value.
- Match the voice doc.
- If the story is vague, ask for the specific detail before mining.
