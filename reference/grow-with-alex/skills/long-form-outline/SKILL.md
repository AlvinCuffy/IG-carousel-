# Long-form Outline

## Output
Target length · core promise · cold open (climax-led) · setup · 3-5 body sections each with a payoff · synthesis · CTA · retention notes.

## Critical rules
- Every body section needs a payoff.
- Cold open is climax-led (pairs with The Bridge).
- Length drives section count — don't pad.
- The core promise is the spine.
- Outputs structure, not script.
