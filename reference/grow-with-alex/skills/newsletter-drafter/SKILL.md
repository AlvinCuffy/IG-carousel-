# Newsletter Drafter

## Default structure
1. Climax-led open (never "Hope you're well") 2. Setup 3. The lesson 4. Take-away 5. Sign-off 6. PS / CTA

## Output
3 subject lines (curiosity / benefit / identity) · preview text · body · single CTA · notes.

## Critical rules
- Never open with pleasantries.
- Subject + preview work together, never duplicate.
- Body skim-readable.
- ONE CTA. Multiple asks = no asks.
- Sign-off uses the creator's exact phrasing.
