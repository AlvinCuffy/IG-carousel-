# Audience Gaps

## Three uses
1. Gap-finding before publishing. 2. Follow-up fuel. 3. Engagement prep — pre-write replies for first-hour velocity.

## Output structure
```
# Audience Gaps — [content title]
## Q1: [The question, in the audience's voice]
**Why they're asking:**
**What to do:** Patch it / OR make it the next post / OR pre-write the reply
## Q2 / Q3
## The biggest gap
```

## Critical rules
- Questions in the AUDIENCE'S voice.
- Tie each to a real gap or curiosity — not generic "tell me more."
- Every question gets all three action options.
- The biggest-gap call is the deliverable.
- Ground in audience insight where available.
