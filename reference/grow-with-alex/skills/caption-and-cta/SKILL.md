# Caption + CTA

## Platform CTA routing
**Instagram:** ManyChat keyword in comments ("Comment WORD"). Short for Reels, line-broken for carousels.
**LinkedIn:** link in body; first line must hook before "see more."
**X/Threads:** reply-bait or thread continuation.
**TikTok:** comment-bait or link in bio. Very short.

## Critical rules
- The CTA is part of the caption. A caption without one is incomplete.
- Each platform gets its own native caption.
- IG defaults to ManyChat keyword unless told otherwise.
- Match the voice doc's banned-phrase list. No emojis unless the voice doc allows.
