# 30 Days of Content. 30 Minutes. One Chat.

Source: `/Grow with Alex/30-days-30-minutes-playbook.docx`. Text extracted 2026-09-09.
(The companion `GWA 30 Days of Content in 30 Minutes (Prompts).docx` is 13 MB and could not be extracted here; its prompts duplicate the ones below.)

The 5-level system. Five prompts. Any niche. Run in ONE chat — context compounding is the whole reason it works.

## Level 1 — Focus
Person + Tension + Path. `I help [person] who feels [tension] by showing them [path].`

- **Person.** Specific enough that one real person could recognise themselves.
- **Tension.** What they feel but can't say.
- **Path.** Where following you leads them.

Give Claude: your bio, 5–10 screenshots of best posts (or a competitor's), analytics, 2–3 competitor accounts.

```
You are helping me design the foundation for a content account. I want something specific, monetisable, and emotionally resonant — not generic.

Below I've shared assets from my page (or accounts I admire). Use these as input:
[Paste: bio, top-performing posts, competitor screenshots, analytics, audience notes]

Step 1: Break down what's actually working in this content. Themes, emotional registers, post formats, hook patterns. Be specific.

Step 2: Give me 3–4 strategic directions I could take the page. For each one:
  - The pivot or angle (1–2 sentences)
  - Who the audience becomes (specific, not "everyone")
  - What they feel but can't say (the tension)
  - Where following the page leads them (the path)
  - The 90-day monetisation angle — what could I actually sell, at what price
  - A one-line focus statement: "I help [person] who feels [tension] by showing them [path]."

Don't be safe. I want directions sharp enough to make me pick one.
```

Lock it: `Locking in direction #[X]. From here on, all output should serve this focus. Don't drift back to the others. If something doesn't fit this direction, flag it.`

## Level 2 — Style
Lock the visual identity so Post 1 and Post 30 look like the same brand. Six elements:

1. **Palette.** 3–5 colours, hex codes, usage rules (dominant / accent / never-use).
2. **Figure/subject style.** How people, characters, or objects appear. Faces shown or hidden. Photographed or illustrated.
3. **Typography treatment.** Display, body, accent. Where text sits on the image. Size hierarchy.
4. **Composition logic.** Framing rules. Negative space. Where the focal point lives.
5. **Anti-style.** The generic AI look you're explicitly rejecting. Naming it stops Claude defaulting back to it.
6. **Signature element.** The one repeating motif that makes posts recognisable from a thumbnail.

```
I'm locking in the focus from Level 1. Now build my visual identity.

Reference images attached — this is the aesthetic I'm pulling from.
[Attach 3–6 reference images]

Step 1: Define my locked style across these six elements:
  1. Colour palette — 3–5 colours with hex codes and usage rules
  2. Figure / subject style — how people or objects appear
  3. Typography — display, body, accent fonts and how text sits on the image
  4. Composition logic — framing, negative space, focal point rules
  5. Anti-style — the generic AI looks we explicitly never do
  6. Signature element — the repeating motif that makes a post recognisably mine

Step 2: Generate 3 starter visuals using Higgsfield (Nano Banana Pro, or ChatGPT Image 2 if it needs heavier text). Each one should demonstrate the locked style, include sample headline text that fits the focus, and be different enough that I can compare and pick.

If a recurring character or signature object would strengthen the brand, suggest it before generating.
```

**The signature trick:** when Claude shows the 3 visuals, push back. Ask for a recurring character or signature object that can carry across all 30 posts. Lock it here before moving on. *If you can't tell the difference between your post and a stock template, neither can anyone scrolling.*

## Level 3 — Plan
Series beat random topics. One credibility series, one shareability series, one conversion series. Each post has a job.

```
The focus is locked. The style is locked. Now build my 30-day content plan.

Constraints:
  - 2–3 recurring series, not random topics. Each series ties to the focus.
  - Each series has a clear job: one for credibility, one for shareability, one for conversion (adjust to my goal: [goal]).
  - Cadence: daily or every other day — you choose what fits.
  - Real dates starting [today's date].
  - Each post slot includes: series name, hook angle, format (carousel / single image / reel), and the "job" it does.

Then give me the season architecture: what this month builds towards by Day 30, the binge loop, and the 2–3 anchor posts to batch first.

Output the calendar as a clean table.
```

## Level 4 — Create
Compounding context: Claude already knows focus, audience, style, series, calendar. Don't re-explain.

### 4A — First 5 covers
```
Generate the first 5 cover images from the calendar.

Rules:
  - Use the locked style from Level 2 (palette, figure, type, composition, signature element). Don't drift.
  - Each cover tells its own story. Different environment, different scene, different emotional register. No duplicate compositions across the 5.
  - Add text on the image where the format calls for it — pull the hook from the calendar entry.
  - Use Higgsfield. Nano Banana Pro for clean text on image, ChatGPT Image 2 if heavier text editing is needed.

After generating, give me a one-line audit of each cover: composition trick used, emotional register, environment, which signature element appears.
```

### 4B — Full carousel from one cover
```
Take cover #[X] and build it into a full carousel. [4–6] slides total, including the cover.

Each slide should:
  - Flow as a sequence. Slide 2 pays off slide 1. Slide 3 deepens. Slide 4 turns. Final slide earns the CTA.
  - Stay locked to the style — palette, type, composition, signature.
  - End on a slide that earns the CTA: save, share, comment, DM keyword.

Generate all slides. Then draft a first-pass caption in my voice.
```

### 4C — Animated cover (optional)
```
Take cover #[X] and animate it into a 5–7 second clip using Higgsfield Seedance 2.0.

Motion brief: subtle, not chaotic. One primary movement (camera push, subject breath, environmental shift). One secondary detail (light, particles, atmosphere). Loop-friendly opening and closing frames. No new text, no new subjects, no new style.

Output: the motion script first, then the generation.
```

Tips: if a cover comes back generic, push back hard ("less generic AI, more [reference], more negative space"). If the signature element slips, name it explicitly: "the [character / object] must appear in every cover."

## Level 5 — Package
5A all 30 captions (CTA mix ~50% save/share, ~25% comment/DM keyword, ~15% link in bio, ~10% none). 5B bio rewrite (3 versions). 5C lead magnet (20–40 page PDF + 3-email welcome sequence). 5D one-page dashboard summarising everything.

## Common ways this breaks
1. Output feels generic → you skipped Level 1.
2. Post 1 and Post 15 don't look related → signature element not locked. Reply: "All future visuals must include [signature]. Don't drift."
3. Calendar feels random → force series: "2–3 series, every post belongs to one, no orphan posts."
4. Captions sound like AI → split context. Go back to the original chat.
